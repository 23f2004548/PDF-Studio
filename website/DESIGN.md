# Design Specification: PDF Studio Landing Page

## Brand Vision
PDF Studio is a high-performance, modern PDF viewer designed for speed and clarity. The landing page should mirror this: ultra-clean, lightning-fast visual cues, and a focus on content over chrome.

## Visual Direction (Inspired by Stitch)
- **Aesthetic**: Minimalist "AI-native" look. Lots of whitespace, subtle depth (glassmorphism), and precise typography.
- **Color Palette**: 
  - Primary: Deep Indigo (#4F46E5) for CTAs.
  - Background: Pure White (#FFFFFF) with Soft Gray (#F9FAFB) sections.
  - Accents: Vibrant Cyan and Violet gradients for feature highlights.
- **Typography**: 
  - Sans-serif (Inter or Geist). 
  - Large, bold headings with tight letter spacing.
  - Monospace accents for technical details.
- **Components**: 
  - Rounded corners (16px+).
  - Subtle borders (1px) with low opacity.
  - High-quality SVG icons and abstract geometric shapes.

## Layout Structure (Mobile-Optimized)
1. **Hero**: Big, bold headline ("PDFs, reimagined."), clear "Download App" CTA, and a high-fidelity mockup of the viewer.
2. **Social Proof**: Minimalist row of "Trusted by" logos or a simple user count badge.
3. **Core Features (The "Stitch" Grid)**: 
   - Feature 1: Instant Search (Speed).
   - Feature 2: Smart Annotations (Interactivity).
   - Feature 3: Cloud Sync (Seamlessness).
4. **Interactive Preview**: A "live" demo component showing a PDF document being manipulated or annotated in real-time.
5. **Testimonials**: Clean cards with subtle drop shadows.
6. **Footer**: Simple links and social icons.

## Motion & Interaction
- Smooth scroll reveals for sections.
- Micro-interactions on buttons (subtle scale up).
- Background "blur blobs" that move slowly to create depth.
